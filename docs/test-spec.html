1. テスト目的

5. 補足

ブラウザの音声再生はユーザー操作後に許可される仕様のため、実機確認では 音量テスト ボタンで現在の音量と音色を確認し、必要に応じて音量スライダーと アラーム音選択を変更する。その後 10秒後にアラームテスト ボタンを押し、 10秒後に音と通知表示が出ることを確認する。 本テストでは、オフライン起動に必要な資産とアラーム処理の存在を自動確認した。
